# 📊 Loan Default Risk Analysis & Interactive Business Intelligence Dashboard

> **An End-to-End Data Analytics Project using Python, SQL, and Power BI to analyze loan default risk, uncover business insights, and build an interactive dashboard for decision-making.**

---

## 📌 Project Overview

Financial institutions process thousands of loan applications every day. One of the biggest challenges they face is identifying high-risk borrowers while maintaining a profitable loan portfolio.

This project analyzes historical loan data to understand borrower behavior, evaluate loan performance, identify factors contributing to loan defaults, and provide actionable business insights through an interactive Power BI dashboard.

The project demonstrates the complete Data Analytics workflow—from raw data preprocessing to SQL analysis and business intelligence visualization.

---

# 🎯 Business Problem

Loan defaults can significantly impact financial institutions by increasing losses and reducing profitability.

This project aims to answer important business questions such as:

- Which customers are most likely to default?
- Which loan categories carry the highest risk?
- How do income, loan grade, and home ownership affect repayment?
- Which regions have the highest lending exposure?
- What insights can help improve lending decisions?

---

# 🎯 Project Objectives

- Clean and preprocess raw loan data
- Perform exploratory data analysis
- Generate business insights using SQL
- Build an interactive Power BI dashboard
- Analyze borrower risk and loan performance
- Support data-driven lending decisions

# 🔍 Key Business Insights

- Higher loan grades generally have lower default rates.
- Borrowers with lower annual income exhibit higher repayment risk.
- Certain loan purposes are associated with higher default rates.
- Loan performance varies across different customer segments.
- Geographic analysis highlights regions with greater lending exposure.
- Borrower verification status influences repayment behavior.
